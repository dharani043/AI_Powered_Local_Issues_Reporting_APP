# Municipality Admin Login Guide

## Step 1: Create Municipality Admins
First, make sure the server is running, then create the admins by visiting:
**http://localhost:5000/api/auth/create-municipality-admins** in your browser

## Step 3: How to Login
1. Go to "Municipality Login" in the sidebar
2. Enter all 4 fields:
   - Email
   - Password
   - Municipality ID
   - Pincode
3. Click Login

## Troubleshooting
- Make sure server is running on port 5000
- Make sure MongoDB is connected
- Visit the create-admins URL first to ensure admins exist
- Check all 4 fields are entered correctly
